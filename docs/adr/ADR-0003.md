## Bağlam

ADR-0002 ile katmanlar Maven modülü olmaktan çıkıp her iş modülünün içinde birer paket oldu. Maven bağımlılıkları yalnızca modül *(JAR)* sınırında denetler; aynı JAR içindeki `domain` paketinin `persistence` paketini import etmesini hiçbir derleyici kuralı engellemez. Kural yalnızca kod incelemesine bırakılırsa ilk acil işte delinir.

## Karar

Bir iş modülünün içindeki paketler arasında izin verilen yönler aşağıdaki matristedir. Satır bağımlılığı kuran paketi, sütun bağımlı olunan paketi gösterir.

| **Kimden/Kime (->)** | **domain** | **api** | **application** | **persistence** | **rest** | **shared-kernel** |
| --- | :---: | :---: | :---: | :---: | :---: | :---: |
| **domain** | - | X | X | X | X | Ok |
| **api** | X | - | X | X | X | Ok |
| **application** | Ok | Ok | - | X | X | Ok |
| **persistence** | Ok | X | X | - | X | Ok |
| **rest** | X | Ok | X | X | - | Ok |
| **shared-kernel** | X | X | X | X | X | - |

- **domain** hiçbir pakete bağımlı değildir. Repository arayüzleri burada, birer *port* olarak durur.
- **api** dışarıya verilen sözleşmedir: komut ve DTO `record`'ları ile façade arayüzleri *(örneğin `CatalogFacade`, `CheckoutFacade`)*. Domain tiplerini görmez; domain değiştiğinde dış sözleşme kendiliğinden değişmez.
- **application** façade'ları uygular ve domain ile api arasındaki çeviriyi mapper'larla yapar. Domain'deki arayüzleri bilir, `persistence`'taki implementasyonları bilmez.
- **persistence** domain'deki repository arayüzlerini uygular.
- **rest** yalnızca `api` ve `shared-kernel`'i görür. Hiçbir paket `rest`'e bağımlı değildir.
- Bir iş modülü başka bir iş modülünün yalnızca **api** paketini kullanabilir *(ADR-0002)*. Örneğin `sales.application`, `catalog.api.CatalogFacade`'ı çağırır; `catalog.domain.Book`'u göremez.

**`api` sözleşmesinin tipleri** *(2026-11-16, Faz 4.4'te eklendi)*. `api` domain'i görmediği için komut, görünüm ve façade imzaları yalnızca JDK tiplerini ve shared-kernel'i kullanır:

- `shared-kernel`'deki kimlikler *(`BookId`, `CustomerId`)* tipli kalır; yalnızca bir modüle ait kimlikler *(`AuthorId`, `CategoryId`, `AddressId`, `OrderId`, `ReviewId`)* sözleşmede `long` olarak görünür ve mapper onları tipli kimliğe çevirir.
- Domain enum'ları *(`Language`, `BookSortField`, `OrderStatus`, `PaymentMethod`, `Role`)* sözleşmede kodları olarak *(`"tr"`, `"SHIPPED"` …)* görünür; mapper bilinmeyen bir kodu `ValidationException` ile reddeder.
- Façade'ların fırlattığı ve istemcinin içine bakması gereken exception'lar *(`CartChangedException`, `PaymentDeclinedException`)* `api` paketindedir; diğerlerini HTTP katmanı yalnızca `Kind` ve `code` ile tanır.
- Misafir sepeti `sales.api.GuestCart` olarak taşınır: web katmanının istekler arasında sakladığı, yalnızca kitap kimliği, adet ve eklendiğindeki fiyatı tutan bir değerdir *(oturumda mı tarayıcıda mı saklanacağı Faz 7'de karara bağlanır)*.
- Her modülün `application` paketinde, paket içi bir mapper vardır *(`CatalogMapper`, `CustomerMapper`, `SalesMapper`, `ReviewMapper`)*.

Ders matrisinden tek fark, `application → persistence` hücresidir: dersin ADR-0003'ünde risk olarak not edilen *("OrderRepository persistence paketinde duruyor")* durumu baştan önlemek için repository arayüzleri domain'de durur ve bu hücre `X` olur.

## Değerlendirilen Alternatifler

| **Alternatif** | **Neden seçilmedi?** |
| --- | --- |
| Java Platform Module System *(module-info.java)* | Modülün hangi paketleri açtığını kontrol eder ama aynı modül içindeki paketler arasındaki yönü ifade edemez. |
| Yalnızca kod incelemesi | Ucuzdur ama tekrarlanabilir değildir. |
| Servislerin domain varlıklarını doğrudan dışarı vermesi | Web katmanı bir `Book` nesnesini alıp `changePrice` çağırabilir. Faz 2'de bu yüzden okuma modeli `record`'ları eklenmişti; bu karar onları `api` paketine taşır. |

## Sonuçlar

- **Olumlu:** Paket yönü her `./mvnw verify` çalıştırmasında doğrulanır ve ihlal build'i kırar.
- **Olumsuz:** IDE yasak bir import yazılırken uyarı vermez.
- **Risk:** ArchUnit 1.5.1, Java 21 `switch` ifadelerinde yalnızca tür eşlemesinde geçen *(bağlanan değişkeni kullanılmayan)* tip referanslarını bağımlılık olarak görmeyebilir *(ders ADR-0009)*.

## Doğrulama

| **Matris kuralı** | **Kim korur?** | **ArchUnit kuralı** |
| --- | --- | --- |
| domain ↛ api, application, persistence, rest | ArchUnit | `domain_does_not_see_other_layers` *(var)* |
| api ↛ domain, application, persistence, rest | ArchUnit | `api_is_a_pure_contract` *(var)* |
| application ↛ persistence, rest | ArchUnit | `application_depends_on_contracts_not_implementations` *(var)* |
| persistence yalnızca domain'i görür | ArchUnit | `persistence_only_sees_domain` *(var)* |
| rest yalnızca api'yi görür; kimse rest'i görmez | ArchUnit | `rest_sees_only_the_contract`, `nothing_depends_on_rest` *(var; `rest` paketleri Faz 5'te gelince dolar)* |
| İş modülleri birbirinin yalnızca api'sini görür | ArchUnit | `ModuleBoundaryTest.<modül>_is_used_only_through_its_api` *(var)* |
| Façade'lar `api` paketindeki arayüzlerdir | ArchUnit | `facades_live_in_api` *(var)* |
