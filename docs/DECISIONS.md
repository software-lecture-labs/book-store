# Mimari Kararlar

Kararlar artık ders notlarındaki biçimde, [`docs/adr/`](adr/README.md) klasöründe ADR olarak tutuluyor.

Bu dosyada daha önce **K-01 … K-15** numaralı kayıtlar vardı. Her birinin yeni ADR karşılığı ve neyin değiştiği [ADR listesinin sonundaki eşleşme tablosunda](adr/README.md#eski-karar-numaraları) yer alıyor. Eski metinler Git geçmişinde duruyor *(`git show 5e5c150:docs/DECISIONS.md`)*.
